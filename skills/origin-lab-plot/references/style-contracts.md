# 样式契约与轴契约

## 轴契约（ace 改良）

普通 2D 必须可见：

- 底 x 轴线、左 y 轴线（厚度默认 2）
- 主刻度、刻度值、轴标题（除非参考图故意没有）

**禁止**用 line 对象假轴。rescale / legend / 分组 / 模板之后要**重刷**，导出前再刷一次。

实现：`apply_style.apply_lab_axes(gl)` 或 `apply_publication_axes(gl)`。  
可选用双重写法兼容版本：`layer.x.showAxes=1` 与 `layer.x.show=1` 都设。

## 实验课 vs 论文

| | 实验课 | 论文（出版默认） |
|---|---|---|
| 框 | 底、左 | 四边框，顶/右无刻度无标签 |
| 次刻度 | 要画要标 | 按期刊 |
| 字号 | 清晰即可 | 约 22 pt 刻度 / 28 pt 轴题（按最终尺寸缩放） |
| 字体 | 默认 | Arial 或期刊指定 |
| 线宽 | 2 | ≥ 2，曲线 2.2 |
| 网格 | 无 | 无 |

LabTalk 四边框见 `scripts/apply_style.py` 的 `PUB_FRAME_LT`。

## 富文本

```text
\g(D)            → Δ
\i(x)            → 斜体 x
E\-(grand)       → 下标
```

导出 PNG/PDF 后目视确认 Unicode/字体。

## 图例

线图优先手动画图例条目，避免自动图例吐列名。分组后再改色会被覆盖——先分组再上色，或分组后重上色。

## 风格与数据边界

样式函数不得改：公式、取值范围、拟合参数、序列科学含义、单位。  
只改样式时，禁止动数据列。

## 验收

1. `python -m py_compile` 改过的脚本  
2. `inspect_origin.py <opju>` 看图页与 plot 数  
3. 打开代表 PNG：四轴/两轴是否在、字是否可读、图例是否对  
4. 不要只凭「脚本没报错」宣布完成
