# 量热实验 ΔT–t 作图规范

来源：本课程作图要求讲义（坐标纸 / 轴 / 范围 / 描点连曲线 / 标坐标 / 图名 / 比例尺 / 次刻度）。

## 图种

- 类型：温差–时间曲线（点 + 光滑线），并可叠前期/后期延长线
- 横轴：`t / min`（时间）
- 纵轴：`ΔT / K`（或课件写法 `ΔT(K)`）。**温差单位用 K**，数值与 °C 温差相同。

## 九条（必须）

1. **软件作图**；作图区 ≥ 图纸一半；页约 16–17 × 11–12 cm
2. **轴旁 = 变量名称 + 量纲**
3. **范围含全部数据 + 余量**；可不从 0 起；轴不贴纸边
4. **描点**：实心圆等，符号中心 = 测值
5. **连光滑曲线**；不能全过点时两侧点数近似相等
6. **标重要坐标** `(x, y)`（延长线交点、拐点等）
7. **图名** = 实验名 + 图名 + 主要结果 + **姓名、日期**（可留空）
8. **比例尺**：主刻度 1/2/5ⁿ，避开 3/4/6/7/8/9；折线近 45°
9. **次刻度也要标注**（主、次都画，按 1/2/5 细分）


## 必须保留的三条（两 skill 共有）

1. **附线性拟合结果表**（Origin 风格，前期/后期各一或标明段名）：
   方程 `y = a + b*x`；绘图；权重（如「不加权」）；
   **截距 a ± δa**、**斜率 b ± δb**、残差平方和、Pearson's r、
   R平方(COD)、调整后R平方。
   示例（前期）：截距 0.03553 ± 0.01989，斜率 0.04589 ± 0.01021，
   残差平方和 0.00183，r = 0.91358，R² = 0.83462，调整 R² = 0.79327。
   写入 `results.txt` 或图注/结果表。

2. **比例尺的选择**：
   ① 能表示测量值的测量精度；
   ② 每小格数值便于读数计算：一般取 **1、2、5** 或 **1、2、5 的 10ⁿ 倍**（n 整数），
      **不取**难读的 3、4、6、7、8、9 或其倍数；
   ③ 比例尺应使直线与横轴交角尽可能接近 **45°**。

3. **次刻度也要标注**：主、次刻度都画；次刻度按 1/2/5 细分；
   必要时刻度旁标数。LabTalk：`layer.x.minor = 4; layer.x.minorlabel = 1`。

## 图上必标

- 前期 / 后期拟合延长线（虚线）
- t = 6 min 垂线（方法 A）或 tm（方法 B）
- 交点 T1、T2 坐标
- `ΔT = T2 − T1` 数值
- （方法 B）阴影曲边三角形 S1、S2，标 `S1 = S2`


### 数值格式（本课程要求）

- **Q_v,m（燃烧热）保留 5 位小数**，单位 kJ/mol（同时可给 J/mol）
- ΔT、T1、T2 保留 4 位小数
- 相对偏差保留 2 位小数

## 数据与计算

- 前期段、后期段线性拟合；R² > 0.85
- **方法 A 6 min 垂线**：ΔT = T2 − T1
- **方法 B 雷诺等面积**：S1=S2 求 tm，再 ΔT
- 对比两法差；热容 `C = (m·q)/ΔT`
- **文献值（本课）**：蔗糖 ΔU_c = **−5645 kJ/mol**（偏差按此计算）

可调用引擎脚本：`origin-lab-plot/scripts/calc_dt.py`、`plot_xy_template.py`

## 禁止

- 无轴标题、假轴线（用 line 冒充）
- 主刻度用 3/6/9 等难读数
- 省略次刻度（本课第 9 条）
- 涂改用户原始数据
